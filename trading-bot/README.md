# Trading Bot (Binance Futures Testnet)

Внимание: это исследовательский проект. Торговля фьючерсами сопряжена с высоким риском. Никаких гарантий прибыли нет. Используйте ТОЛЬКО тестнет/демо, пока не убедитесь в корректности работы и рисках.

## Возможности
- Мульти-тикер и мульти-таймфрейм сбор данных с Binance USDT-M Futures (testnet по умолчанию)
- Базовые стратегии:
  - MTF Momentum (тренд + RSI/MACD, фильтр волатильности ATR)
  - Fast Scalper (прорывы Bollinger + моментум)
- Риск-менеджмент: фиксированный риск на сделку, ATR-стоп, ограничение дневного убытка, ограничение числа одновременно открытых позиций
- Бэктест движок (pandas): отчеты по PnL, win rate, max drawdown, Sharpe
- Уведомления в Telegram (REST, без сторонней библиотеки)
- Paper-trading по умолчанию; возможность включить размещение ордеров на testnet

## Быстрый старт
1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Заполнить `.env` на основе `.env.example`.
3. Запуск бэктеста (пример):
   ```bash
   python -m trading_bot.backtest_run --symbol BTCUSDT --interval 5m --days 60 --strategy mtf
   ```
4. Запуск лайв-лупа (paper):
   ```bash
   python -m trading_bot.main
   ```

## Переменные окружения (.env)
См. `trading_bot/config.py` и пример `.env.example`. Ключевые:
- BINANCE_API_KEY, BINANCE_API_SECRET — ключи testnet (для paper можно не указывать)
- BINANCE_TESTNET=true
- TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID — для уведомлений
- LIVE_TRADING=false (по умолчанию)

## Стратегии (обзор)
- MTF Momentum: подтверждение тренда старшим ТФ (напр. 1h) + вход на младшем (5m) при импульсе; фильтрация по ATR/волатильности, RSI и MACD диверсификаторы.
- Fast Scalper: краткосрочные импульсы на 1m/5m при выходе за Bollinger и развороте моментума; жесткие стопы ATR, выгрузка по тейку/трейлингу.
